# 💻 Sistema Desktop com Banco de Dados (Projeto de Avaliação)

Aplicação desktop desenvolvida em **C# (Windows Forms)** durante o curso Técnico em Informática, com foco na integração com banco de dados relacional, navegação entre múltiplas telas e manipulação de registros.

### ✨ Estrutura e Funcionalidades
- **Múltiplas Interfaces (`Form1`, `Form2`, `Form3`):** Fluxo completo de telas para interação com o usuário (ex: tela inicial/login, cadastro e consulta/gerenciamento de dados).
- **Persistência de Dados:** Conexão configurada via `App.config` para armazenamento, leitura e atualização de informações em banco de dados.
- **Programação Orientada a Objetos:** Estruturação de eventos, validações de campos e regras de negócio em C#.

### 🛠️ Tecnologias Utilizadas
- C# (.NET Framework / Windows Forms)
- Visual Studio
- Banco de Dados Relacional (SQL)

### 🚀 Como executar
1. Faça o download ou clone este repositório.
2. Abra o arquivo da solução (`.sln` / `.csproj`) no **Visual Studio**.
3. Configure a string de conexão com o seu banco de dados local no arquivo `App.config`, se necessário.
4. Pressione **F5** para compilar e executar o sistema.
